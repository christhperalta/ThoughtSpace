# Thought Space


**Thought Space** is an application designed to store and manage personal notes. It was developed using **Jetpack Compose** and integrates the **Room database**, as well as the latest **Navigation 3**.  Although it is a relatively simple project, it provided me with valuable experience and allowed me to learn several concepts that I plan to apply in future developments.
